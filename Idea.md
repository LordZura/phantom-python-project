# The Game Idea

## main idea:
- a text based RPG game, you start in a world with stuff, its gonna be a lot basically, you'll have a lot of choices.



## rules/details:
- starting logic
-- ask name, family name, chose from multiple classes that will have different traits, like warrior, archer, and mage for now. important stats are strength, stamina, mana(only important for mages, but is possible to be with other though stuff like magic items or potions and stuff.) 
-- starts with some loot, items need to be advanced so that each has many stats. 

- for testing, starting with making tests for battles, so we need encounters, 

- always have options: 
- Map: list all the places in the world, categories of countries, then clicking one sends you to new list of places it has, each will have their data, if its explored already or not, is not discovered by anyone, its unknown, distance between you and that place... picking one sends into options: Travel (for now only this), which will start the journey to that place, the travel is not instant, it depends on your transport (foot, a horse (horse stats as well) or anything else) it works with days, each day you have to decide again, with list of choices such as continuing the travel, stopping (you stay at where you last where)  or random encounter choices, for example depending on your *_robberyChance* value, some robbers might appear, the chance value also depends on lot of things like your equipment, the robbers power and count. in that encounter you have nothing else to do.
